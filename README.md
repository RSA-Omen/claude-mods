# claude-mods

Claude Code mods.

| Mod | What it does |
| --- | --- |
| [pane-glow](plugins/pane-glow) | Coloured band above the prompt showing whether a chat is running, waiting on child agents, or waiting on you |

## Install

In the Claude desktop app: click **+** next to the prompt box → **Plugins** → **Add marketplace** → `RSA-Omen/claude-mods`, then **Add plugin** → `pane-glow`.

In a terminal:

```
/plugin marketplace add RSA-Omen/claude-mods
/plugin install pane-glow@claude-mods
```
